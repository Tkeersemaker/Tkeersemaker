## Padel Amsterdam — Beschikbaarheid tracker

An online tool that shows **real-time padel court availability** across Amsterdam venues, lets you deep-link directly to booking on Playtomic, and alerts you via Telegram when a slot opens up.

### Features
- Live hour-by-hour availability grid across major Amsterdam venues
- One-click "Book on Playtomic" deep-links for every available slot
- Telegram alerts — subscribe to a time window and get notified when a court opens
- Auto-refreshes every 2 minutes

See `backend/` and `frontend/` for the source code.
